What CyberTrace offers

A compact set of monitoring features, built to show real-time data flow end to end.

Live event feed

New demo events appear the moment the backend sends them, with name, severity and time.

Severity counters

See how many High, Medium and Low events arrived in your current session.

Instant notifications

A short alert slides in for every new event so you do not miss one while scrolling.

Full dashboard

The main dashboard shows the complete monitoring interface in one place.

Platform overview

CyberTrace has two parts that talk to each other over one WebSocket connection.

Backend

A Node.js and Express server on Render. It emits a threatUpdate event about every 10 seconds.

Frontend

This site and the dashboard listen to the backend with the Socket.IO client and update the page instantly.

How it works

From server event to your screen in four steps.

  1. Backend generates an event

    The server creates a demo event with a name and a severity level.

  2. Socket.IO sends it

    The event is broadcast on the threatUpdate channel.

  3. Browser receives it

    This page checks the data is valid before using it.

  4. Screen updates

    The feed, counters and notification update together.

Limitations

Please read before you rely on this project.
  • All events are generated demo events. They are not real cyberattacks or real threat detection.
  • Counters and the feed reset when you reload the page. Events are not stored.
  • The backend runs on a free Render plan, so the first connection after idle time can take up to a minute.
